## 📖 About The Project

**FLAMES (Friends, Lovers, Affection, Marriage, Enemies, Siblings)** is the beloved nostalgic relationship game, crafted into an interactive modern web application with an enchanting romantic aesthetic.

Simply enter two names, click **Calculate**, and watch the letters eliminate step-by-step in real time to reveal your compatibility score and relationship destiny!

---

## 🌟 Features & Highlights

- 💘 **Staggered FLAMES Elimination**: Watch each common letter strike through dynamically following the authentic FLAMES counting algorithm.
- 📊 **Dynamic Compatibility Meter**: Calculates a unique relationship percentage with smooth gradient animations.
- 🎊 **Romantic Celebration**: Special particle confetti celebration when destiny lands on *Lovers* or *Marriage*.
- 🔍 **"Reveal Our Calculation" Modal**: An interactive breakdown explaining the character cancellation count and mathematical outcome.
- 📋 **One-Click Share**: Effortlessly copy or share your love story result via the native Web Share API or clipboard.
- 📱 **Fluid Responsiveness**: Modern glassmorphic cards, glowing embers, and touch-optimized layout for mobile, tablet, and desktop screens.

---

## 🎨 Design & Aesthetic

- **Enchanted Theme**: Atmospheric dark romance aesthetic featuring cosmic lighting, glowing rose petals, and dynamic rain and fire embers.
- **Glassmorphism**: Translucent layered cards, blurred backdrops, and subtle neon gradient glows.
- **Modern Typography**: Elegant script calligraphy (*Allura*, *Great Vibes*) combined with clean sans-serif typography.

---

## 🛠️ Technology Stack

- **Structure**: HTML5 (Semantic elements, accessible layout)
- **Styling**: Vanilla CSS3 (Custom properties, clamp typography, glassmorphism, responsive grid & flexbox)
- **Logic**: Vanilla JavaScript (ES6+ async flows, HTML5 Canvas animation, character cancellation algorithm)
- **Server**: Lightweight Node.js / Express server for serving the application and calculation utilities

## 🚀 How to Run Locally

You can run this project locally in seconds:

### Option 1: Direct Browser Run (No Setup Needed)
Simply open `index.html` (or `frontend/index.html`) in any web browser or use the **VS Code Live Server** extension.

### Option 2: Run with Node.js Server
```bash
# 1. Clone the repository
git clone https://github.com/dullamanojreddy/flames.git
cd flames

# 2. Install dependencies
npm install

# 3. Start the application
npm start
```

Visit `http://localhost:5000` in your browser.
